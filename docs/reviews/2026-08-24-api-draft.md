# Public API draft review

Date: 2026-08-24

## Scope

Independent read-only reviews covered the adjacent Ada declarations,
`contracts.md`, and their consistency with `docs/architecture.md`. The review
used the repository P0/P1/P2 rubric. These declarations remain a published
draft, not a frozen implementation API, until the existing Serde and Type IR
tasks complete their consumer reviews.

## Resolved findings

- P1 lifecycle findings: defined every parser and writer state transition,
  profile presence, reset behavior, destination ownership, abort precedence,
  field validity, rejected-call behavior, and controlled finalization cleanup
  for an abandoned active writer transaction.
- P1 ownership findings: made parser/writer instances single-owner and
  nonconcurrent, required serialized access to their caller-owned collaborators,
  and scoped finalization guarantees to normal exit and synchronous unwinding;
  asynchronous task abort during mutation requires caller-side deferral.
- P1 fragment findings: removed retained access values; defined arbitrary-bound
  count ranges, absolute coordinates, raw-only split fragments, inline decoded
  scalars, exact source coverage, and normalized chunk invariance.
- P1 boundedness findings: replaced empty private records with caller-backed
  structural, duplicate-index, name, and lexical carry storage.
- P1 policy findings: narrowed the initial public compatibility identity to
  `No_Extensions_V1` and BOM identity to `Reject_BOM_V1`; no unapproved comment,
  trailing-comma, nonstandard-number, nonfinite, raw-control, replacement, or
  BOM-ignore behavior is selectable.
- P1 duplicate findings: specified exact decoded UTF-8 equality, crit-bit arena
  capacities, aggregate leaf/internal-slot charging, deterministic work, and
  later-name failure offsets.
- P1 accounting findings: separated caller-owned semantic budgets from
  nondeniable observational counters, derived charge/counter values from
  `Ada.Streams`, and defined saturation and ordinal-exhaustion behavior.
- P1 destination findings: mapped every begin/write/commit/abort outcome to a
  state, primary or secondary error, exact coordinate, cleanup obligation, and
  nonpublication guarantee.
- P2 surface findings: removed unused extension DFA states, unused error codes,
  mutable budget arguments with no charge, and undocumented mathematical carry
  bounds.
